# Smart Campus AI

## Final Year BCA Project

Smart Campus AI is an individual academic project developed as part of my Bachelor of Computer Applications (BCA) final year.

The project is designed to provide a smart campus application with dedicated interfaces for students, faculty members, and administrators.

## Project Structure

- `app.py` – Main application.
- `model.py` – Machine learning model functionality.
- `sentiment.py` – Sentiment-related functionality.
- `templates/` – HTML pages and dashboards.
- `static/` – CSS and static assets.

## User Modules

- Student Dashboard
- Faculty Dashboard
- Admin Dashboard
- User Profile Pages

## Technologies

- Python
- HTML
- CSS
- Machine Learning
